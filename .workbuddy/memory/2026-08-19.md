# 2026-08-19 工作日志

## 项目计划：前置联动日期偏差修复（关键）
- 现象：后置任务开始时间不是「前置任务结束时间 + 1 天」（实际 +2 天）。
- **根因**：后端 `schedule.js` 的 `addDays(date, n)` 语义是「+n 天」，而前端 `schedule-date.js` 是「+n-1 天」（含首尾）。前后端不一致 → 后端所有日期换算多 1 天：反向联动「前置结束 = 后置开始 - 1」被算成「= 后置开始」(`addDays(开始,0)`)、正向级联「后置开始 = 前置结束 + 1」被算成「+2」(`addDays(结束,2)`)。
- **修复**：后端 `addDays` 改为含首尾语义（`date + n - 1`，与前端一致），全部 14 处调用点按其意图参数自动正确。已验证：真实数据联动后 B 结束 = A 开始 - 1 ✓。
- **历史数据**：`server/fix-predecessor-dates.mjs`（dry-run 默认 / `--apply` 执行）级联修正「后置开始 ≠ 前置结束+1」的任务，扫描出 23 个（液冷超节点模板链 L5→原理图→Layout→PCB→PCBA→PowerOn→测试 层层 +1）。**执行前需用户确认**（可能收紧手动排期的空档）。
- 教训：**前后端日期工具函数必须语义一致**（含首尾约定）。后端 addDays 注释已补示例（`addDays("2026-08-21",5)="2026-08-25"`、`addDays(A开始,0)=A开始-1`、`addDays(B结束,2)=B结束+1`）。
- **执行结果（10:26）**：用户确认后 `node fix-predecessor-dates.mjs --apply` 级联修正 23 个任务全部成功；复扫 0 残留；抽查 L5 开始 8/28 = L4 结束 8/27 +1 ✓、PowerOn 1/18 = PCBA 结束 1/17 +1 ✓。db 文件被 gitignore，无需提交。
